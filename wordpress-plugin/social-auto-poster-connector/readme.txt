Connects WordPress directly to CreatorFlow Social Auto Poster SaaS with Multi-Title variations per Facebook page and first-comment article link.

== Description ==

Social Auto Poster Connector enables WordPress publishers to:
1. Add multiple social titles (1 title per line) in the post editor.
2. Automatically push published articles to CreatorFlow Social Auto Poster.
3. Generate distinct image cards for each connected Facebook Page.
4. Auto-inject the article URL in the first comment for maximum reach.

== Installation ==

1. Upload the `social-auto-poster-connector` folder to the `/wp-content/plugins/` directory, or upload the ZIP file through Plugins > Add New > Upload Plugin.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to Settings > Social Auto Poster to configure your Webhook URL and Secret Key.
4. When writing a post, use the "Social Auto Poster — Multi-Page Titles" box to add alternative headlines for your Facebook pages!
